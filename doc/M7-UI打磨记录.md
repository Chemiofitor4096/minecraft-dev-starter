# M7 UI 打磨记录

> 日期：2026-10-31 · 结论：**完成**。图标、空态、动效、密度与文案统一到系统风格；视觉判断仍需人眼，自动化只能守住"不跑偏"的底线。

## 1. 图标

系统图标库（`@deepseek-ai/dsh-client-ui-primitives`）里有 `IconPlayOutlineRegular`、`IconStopFillRegular`、`IconRefreshOutlineRegular`、`IconWarningOutlineRegular`，但**没有直接 import**：

- 我们的客户端是懒 CJS，顶层 `require` 一旦在某运行时里解析不到，整个 bundle 都会挂（`defineTool` 那边已经吃过一次"解析不到"的亏）。
- `dsh-better-sidebar` 对库里没有的字形也是自己画 SVG，沿用同一做法风险最低。

`src/client/icons.js` 手绘了四个 16px 字形：播放、停止、刷新、警告。统一 1.5 描边、`currentColor`、`aria-hidden`，与系统图标同一套视觉语言。将来要换成官方图标，只需替换这一个文件。

## 2. 空态与骨架

| 位置 | 之前 | 现在 |
|---|---|---|
| 浮层首扫 | 一行"正在扫描…" | 三条灰条骨架 + 提示 |
| 详情页无工程 | 一行文字 | 骨架（扫描中）或说明（扫完没找到） |
| 日志标签加载中 | 空 `<pre>` | 骨架 + "正在读取日志…" |

骨架用 `--dsw-alias-interactive-bg-hover` 铺底，不写死任何色值。

## 3. 动效

- 浮层：`translateY(-4px) → 0` 淡入，120ms。
- 运行状态点：`opacity 1 → .45 → 1` 呼吸，1.6s；只在"有实例在跑"时挂 `data-pulse="true"`。
- 按钮/选项：背景、文字、描边 120ms 过渡。
- `@media (prefers-reduced-motion: reduce)` 里全部关掉（动画与过渡）。

## 4. 密度与文案

- 胶囊目标名在窄窗口截断，完整路径留在 tooltip。
- 徽标高度 20、按钮 24、选项行 22，与系统控件标尺一致。
- 文案去内部术语：
  - "推测" → **未验证**（tooltip 写"按 loader 惯例推测，尚未验证"）
  - "暂未看到就绪标记" → **还没看到启动信号，可能仍在构建**
  - 警告列表改为图标 + 文本，不再用 `·` 开头。

## 7. 反馈修正：单选只画当前工程

**问题**（用户看截图提出）：浮层里每个工程的 `Client` 都是实心圆点，看起来"全都选中了"，于是不知道 ▶ 会启动哪一个。

**原因**：选择是**按工程**记的（`selection[projectRoot] = targetKey`）。每个工程各有一个选中项本身没错，错在把四个工程的单选**同时画出来**，而"全局只有一个 ▶"的语义没有在界面上体现；胶囊又只显示 `Client`，没说属于哪个工程。

**修正**：

- 只有**当前工程**渲染单选列表；其它工程收成一行摘要（`目标 Client（共 2 个）` + 「切到这里」）。
- 当前工程标题上加 `当前` 徽标，选中项仍只有一个。
- 胶囊在工作区有多个工程时带上工程名：`Example Mod · Client`。
- `capsuleSummary()` 进 `selection.js`，由单测覆盖（多工程带名、单工程不带、空工程兜底）。

结果：任意时刻浮层里可见的实心圆点最多一个，和胶囊、▶ 指向完全一致。

## 8. 细节：分割线与按钮化

第二次看截图后补的两处：

- **工程之间加内缩分割线**：`::before` 画 1px、左右各缩进 10px 的 `--dsw-alias-hairline`，不做通栏；当前工程仍靠底色区分。原先两个工程上下贴在一起，读起来是一坨。
- **动作从文字链接换成小按钮**：`查看详情` → 「工程详情 ›」，`切到这里` → 「✓ 切换到此工程」；刷新类动作也统一成 `.mcdev-mini`（22 高、4 圆角、描边、图标 + 文字）。非当前工程把"切换"和"详情"放在同一行右对齐，少一行高度。
- `.mcdev-link`（蓝色下划线文字链）已从样式里删除——没有地方再用它了。

## 9. 第三轮：列表与选择拆开

再看截图，问题从"分隔线"升级成结构性的：

1. **表头和滚动列表没有边界**：路径和工程行糊在一起。
2. **选工程时整块跳动**：当前工程展开单选项、其它工程只有一行，高度不同。
3. **动作重复**：每行都挂「切换到此工程」「工程详情」。
4. **无用信息**：`目标 Client（共 2 个）` 是给不了新信息的注脚。

改成三层固定结构：

```
┌ 表头（不滚动）  MC 工程            ⟳
│                C:\...\test
├ 列表（滚动）    ○ e2e-project   Fabric 1.21.1
│                ● e2e-fail      Fabric
│                ○ architectury  多平台
├ 选择区（固定）  运行目标  ◉ Client
│                           详情 ›
└
```

- 表头用通栏 `hairline` 与列表分开，路径单行省略。
- 列表每行固定 30px：名字 + 右侧 `loader · 版本`，**没有按钮、没有展开**；当前行用底色 + 加粗区分。
- 选中工程的目标只在底部固定区出现；有实例在跑时在"运行目标"旁边带一个状态点。
- 「详情」只剩一处（选择区右上），「刷新」只剩一处（表头图标按钮）。
- 删掉 `目标 Client（共 N 个）` 这类复述性文字。

顺带清掉不再使用的 `.mcdev-project`、`.mcdev-project-actions`、`.mcdev-divider` 样式。

## 10. 胶囊截断策略

多工程工作区里胶囊会显示 `工程名 · 目标名`，标题栏宽度不够时整串被截成
`Example Neo Mod · GameTestSer…`——被切掉的恰好是**可操作的目标名**。

改成两段布局：工程名 `flex:1 + ellipsis`，目标名 `flex:none`。窄的时候让步的是工程名，
完整名字留在 tooltip 里；只有单工程时干脆不显示工程名。

## 11. 已知限制

1. **视觉判断只能靠人眼**：本轮只做了结构性的统一，配色/间距是否符合你的审美，需要你看一眼。
2. **没有动画的"进入/退出"不对称**：浮层关闭是瞬间消失。做退出动画要维护卸载状态，成本比收益高，先不做。
3. **图标是自绘的**：字形与系统图标在细节笔画上可能略有差异（比如播放三角的圆角）。
