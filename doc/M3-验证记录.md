> 日期：2026-10-31 · 结论：**通过**。标题栏胶囊成为真正的入口：显示当前选中的目标、状态点与启停按钮；浮层收敛成单选；`DEV_AUTO_OPEN` 已下线。

## 1. 这一版改了什么

| 位置 | 之前（M2） | 现在（M3） |
|---|---|---|
| 标题栏胶囊 | 显示 loader + MC 版本 | 状态点 + **选中的目标名** + ▶/⏹ |
| 浮层 | 每个目标一排按钮 | **单选列表**，按模块分组；动作只在胶囊上 |
| 目标记忆 | 无 | 按工程记在 `localStorage`，下次还是上次那个 |
| 详情页 | 每目标一排按钮 | 只显示选中的目标 + 启停，提示去胶囊换目标 |
| 自动打开标签 | `DEV_AUTO_OPEN = true` | 移除 |

选择逻辑拆到 `src/client/selection.js`（纯函数）：`groupByModule` / `selectedTarget` / `capsuleText` / `targetKey`，由 7 个单测覆盖。

## 2. 为什么这么收敛

同一个工程同时只能跑一个实例（服务端强制）。摆一排按钮会让人以为可以并行点，点了却被拒——不如让列表只表达"选哪个"，开与停收在一个按钮上。这也回到你最早给的那张参考图：一个下拉 + 一个播放键。

## 5. 已知限制

1. **选择存在浏览器本地**（`localStorage`），换浏览器或换设备不跟着走。跨设备同步没必要，真要跟仓走再考虑写进工程 `.dsh/`。
2. **胶囊宽度**：目标名 + 模块前缀在窄窗口会被省略号截断，完整路径在 tooltip 里。
3. **没有过渡动画**：浮层是直接显示/隐藏，`prefers-reduced-motion` 之类的打磨留到最后的 UI 装饰阶段（你提到的那一轮）。
